# Limites

- Le dataset fourni doit être documenté avant interprétation
- La définition de la cible doit être confirmée
- Le modèle ne garantit pas le remboursement
- Les performances dépendent de la qualité du dataset
- Le score n'est pas une décision bancaire automatique
- Les données peuvent contenir des biais
- La validation humaine reste obligatoire
- Le GPU Kaggle dépend des quotas disponibles
- Le dataset complet ne doit pas être exposé sans autorisation
